Pocket Universe — Version 1.4A

Added today:
- Added 10 blue alien Beobaka bunnies on Ivis with hopping, wandering, tree avoidance, and planet-attached movement.
- Added Beobaka harvesting with axe hits, red hit flash, falling death animation, smoke effect, and automatic hidden respawns so Ivis always has 10 bunnies.
- Added Raw Beobaka meat drops and Cooked Beobaka meat items.
- Added campfire cooking for Raw Beobaka, including a physical raw-meat model on the campfire and a cooked-meat drop when finished.
- Added hunger and health survival systems with 100 Hunger and 100 Health, starvation damage, hunger-based movement restrictions, and contextual stamina display.
- Added food effects: Raw Beobaka restores 10 hunger; Cooked Beobaka restores 30 hunger and retains its stamina benefit.
- Added the new Player.glb character model with improved walk, sprint, jump, eating, and crouch animations.
- Added smooth Minecraft-style crouching with C, while X toggles the camera.
- Added hand-held item attachment so tools and food follow the player's hands during animations.
- Added the new Blockbench shirt with pivoted sleeves that follow the player's arms and torso.
- Added Account-tab character customization with a 3D player preview and 12 selectable skin colors.
- Added Helna-controlled shirt colors so the shirt uses the color purchased/equipped from Helna while skin color is customized separately in the Account tab.
- Added Screenshot Mode on the backquote (` / ~) key to hide the HUD without pausing gameplay.
- Added key rebinding support for Screenshot Mode and a recovery path for restoring Escape to the Escape key.
- Added various player-model polish fixes, including model facing, arm/leg swing syncing, hat placement, and smoother animation blending.

Pocket Universe Day 13 – Aurora Glowfish

Added 28 small 3D bioluminescent glowfish in four schools, one school per Aurora lake. Fish inherit Aurora orbit/rotation, swim in circular paths around their lake, gently bob, and scatter slightly when the player approaches.


Campfire visual refinement: replaced the single wobbling cone flame with several low-poly irregular flame tongues plus a brighter inner flame core, with independent subtle flicker/sway.

## Day 14 — Blue Bunny wildlife
This build adds peaceful, indestructible blue alien bunnies to Ivis with hopping, wandering, player-proximity fleeing, and planet-attached movement so they follow Ivis during rotation and solar orbit.
